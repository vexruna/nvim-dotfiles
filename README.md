# nvim-dotfiles

## Description

This is my personal neovim config that I made after nearly 2 weeks of digging and absorbing new information.

```
    ● blink.cmp
    ● catppuccin

    ● telescope.nvim
    ● tiny-inline-diagnostic.nvim
```
### Installing
```
git clone https://github.com/vexruna/nvim-dotfiles ~/.config/nvim/
```

### Keymaps

[Shift + e] - Toggles nvim-tree

[Alt + hjkl] - Instantly switch between windows in any mode
