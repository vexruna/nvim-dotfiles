# nvim-dotfiles

## Description

This is my personal neovim config that I made after weeks of digging and absorbing new information.

### Full list of plugins

- neovim/nvim-lspconfig
- ibhagwan/fzf-lua
- mason-org/mason.nvim
- nvim-tree/nvim-web-devicons
- nvim-lualine/lualine.nvim'
- nvim-treesitter/nvim-treesitter
- Saghen/blink.cmp
- L3MON4D3/LuaSnip
- rafamadriz/friendly-snippets
- nvim-lua/plenary.nvim
- lewis6991/gitsigns.nvim
- folke/which-key.nvim
- stevearc/conform.nvim
- mfussenegger/nvim-lint
- RRethy/base16-nvim


### Installing

```
git clone https://github.com/vexruna/nvim-dotfiles ~/.config/nvim/
```

### Keymaps

[Alt + hjkl] - Instantly switch between windows in any mode
